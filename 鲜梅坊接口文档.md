# 鲜梅坊接口文档-V1.0

## 1. 用户相关接口

### 1.1 注册

#### 1.1.1 基本信息

> 请求路径：/user/register
>
> 请求方式：POST
>
> 接口描述：该接口用于注册新用户

#### 1.1.2 请求参数

请求参数格式：application/json

请求参数说明：

| 参数名称 | 说明     | 类型   | 是否必须 | 备注                                               |
| -------- | -------- | ------ | -------- | -------------------------------------------------- |
| username | 用户名   | string | 是       | 5~16位非空字符，只能包含字母、数字和下划线         |
| password | 密码     | string | 是       | 8~20位非空字符，必须包含大小写字母，数字，特殊符号 |
| phone    | 手机号码 | string | 是       | 11位正确手机号码格式                               |

请求数据样例：

```json
{
    username: "zhangsan",
    password: "123456",
    phone: "15748374633"
}
```

#### 1.1.3 响应数据

响应数据类型：application/json

响应参数说明：

| 名称    | 类型   | 是否必须 | 默认值 | 备注                  | 其他信息 |
| ------- | ------ | -------- | ------ | --------------------- | -------- |
| code    | number | 必须     |        | 响应码, 0-成功,1-失败 |          |
| message | string | 非必须   |        | 提示信息              |          |
| data    | object | 非必须   |        | 返回的数据            |          |

响应数据样例：

```json
{
    "code": 0,
    "message": "操作成功",
    "data": null
}
```

### 1.2 登录

#### 1.2.1 基本信息

> 请求路径：/user/login
>
> 请求方式：POST
>
> 接口描述：该接口用于登录

#### 1.2.2 请求参数

请求参数格式：application/json

请求参数说明：

| 参数名称 | 说明   | 类型   | 是否必须 | 备注                                               |
| -------- | ------ | ------ | -------- | -------------------------------------------------- |
| username | 用户名 | string | 是       | 5~16位非空字符，只能包含字母、数字和下划线         |
| password | 密码   | string | 是       | 8~20位非空字符，必须包含大小写字母，数字，特殊符号 |

请求数据样例：

```json
{
    username: "zhangsan",
    password: "123456"
}
```



#### 1.2.3 响应数据

响应数据类型：application/json

响应参数说明：

| 名称    | 类型   | 是否必须 | 默认值 | 备注                  | 其他信息 |
| ------- | ------ | -------- | ------ | --------------------- | -------- |
| code    | number | 必须     |        | 响应码, 0-成功,1-失败 |          |
| message | string | 非必须   |        | 提示信息              |          |
| data    | string | 必须     |        | 返回的数据,jwt令牌    |          |

响应数据样例：

```json
{
    "code": 0,
    "message": "操作成功",
    "data": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJjbGFpbXMiOnsiaWQiOjUsInVzZXJuYW1lIjoid2FuZ2JhIn0sImV4cCI6MTY5MzcxNTk3OH0.pE_RATcoF7Nm9KEp9eC3CzcBbKWAFOL0IsuMNjnZ95M"
}
```



#### 1.2.4 备注说明

> 用户登录成功后，系统会自动下发JWT令牌，然后在后续的每次请求中，浏览器都需要在请求头header中携带到服务端，请求头的名称为 Authorization，值为 登录时下发的JWT令牌。
>
> 如果检测到用户未登录，则http响应状态码为401

### 1.3 获取用户信息

#### 1.3.1 基本信息

> 请求路径：/user/info
>
> 请求方式：GET
>
> 接口描述：该接口用于获取当前已登录用户的详细信息

#### 1.3.2 请求参数

无

#### 1.3.3 响应数据

响应数据类型：application/json

响应参数说明：

| 名称          | 类型   | 是否必须 | 默认值 | 备注                  | 其他信息 |
| ------------- | ------ | -------- | ------ | --------------------- | -------- |
| code          | number | 必须     |        | 响应码, 0-成功,1-失败 |          |
| message       | string | 非必须   |        | 提示信息              |          |
| data          | object | 必须     |        | 返回的数据            |          |
| \|-id         | number | 非必须   |        | 主键ID                |          |
| \|-username   | srting | 非必须   |        | 用户名                |          |
| \|-nickname   | string | 非必须   |        | 昵称                  |          |
| \|-email      | string | 非必须   |        | 邮箱                  |          |
| \|-phone      | string | 必须     |        | 手机号码              |          |
| \|-avatar     | string | 非必须   |        | 头像地址              |          |
| \|-createTime | string | 非必须   |        | 创建时间              |          |
| \|-updateTime | string | 非必须   |        | 更新时间              |          |

响应数据样例：

```json
{
    "code": 0,
    "message": "操作成功",
    "data": {
        "id": 5,
        "username": "wangba",
        "nickname": "",
        "email": "",
        "phone": "",
        "avatar": "",
        "createTime": "2023-09-02 22:21:31",
        "updateTime": "2023-09-02 22:21:31"
    }
}
```



## 2. 商品模块

### **2.1 获取商品分类树**

- **URL**: `/api/category/tree`

- **Method**: GET

- **成功响应**:

  ```json
  {
    "code": 0,
    "data": [
      {
        "id": 1,
        "name": "电子产品",
        "children": [
          {"id": 101, "name": "手机"},
          {"id": 102, "name": "笔记本"}
        ]
      }
    ]
  }
  ```

------

#### **2.2 分页查询商品列表**

- **URL**: `/api/goods/list`

- **Method**: GET

- **Query Params**:

  - `page=1`（默认1）
  - `pageSize=10`（默认10）
  - `categoryId=101`（可选）
  - `keyword=手机`（可选）

- **成功响应**:

  ```json
  {
    "code": 0,
    "data": {
      "total": 50,
      "list": [
        {
          "id": 10001,
          "name": "iPhone 15",
          "price": 6999.00,
          "mainImage": "https://xxx.com/iphone.jpg",
          "status": 1
        }
      ]
    }
  }
  ```

------

### **3. 订单模块**

#### **3.1 创建订单**

- **URL**: `/api/order/create`

- **Method**: POST

- **Headers**: `Authorization: Bearer {token}`

- **请求体**:

  ```json
  {
    "cartIds": [2001, 2002],  // 购物车项ID数组
    "addressId": 3001         // 收货地址ID
  }
  ```

- **成功响应**:

  ```json
  {
    "code": 0,
    "data": {
      "orderId": 5001,
      "totalAmount": 13998.00
    }
  }
  ```

- **错误场景**:

  - 400: 库存不足
  - 404: 地址不存在

------

#### **3.2 取消订单**

- **URL**: `/api/order/cancel/{orderId}`

- **Method**: POST

- **Headers**: `Authorization: Bearer {token}`

- **成功响应**:

  ```json
  {
    "code": 0,
    "data": "订单已取消"
  }
  ```

- **错误场景**:

  - 403: 非订单所有者无法操作
  - 400: 订单已支付，无法取消

------

### **6. 管理员专属接口**

#### **6.1 审核商品（需管理员权限）**

- **URL**: `/api/admin/goods/audit`

- **Method**: POST

- **Headers**: `Authorization: Bearer {token}`

- **请求体**:

  ```json
  {
    "goodsId": 10001,
    "status": 1,  // 1-通过 2-拒绝
    "reason": "图片不符合规范"  // 拒绝时必填
  }
  ```

- **成功响应**:

  ```json
  {
    "code": 0,
    "data": "审核完成"
  }
  ```
