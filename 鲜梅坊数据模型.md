## **1. 用户模块**

### **用户表 (user)**

| 字段名      | 类型         | 说明                       | 约束                        |
| :---------- | :----------- | :------------------------- | :-------------------------- |
| id          | BIGINT       | 用户ID（雪花算法生成）     | 主键                        |
| username    | VARCHAR(32)  | 用户名                     | 唯一索引                    |
| password    | VARCHAR(128) | 加密密码（BCrypt）         | 非空                        |
| phone       | VARCHAR(11)  | 手机号                     | 唯一索引                    |
| email       | VARCHAR(64)  | 邮箱                       | 唯一索引                    |
| avatar      | VARCHAR(255) | 头像URL                    |                             |
| create_time | DATETIME     | 创建时间                   | 默认CURRENT_TIMESTAMP       |
| update_time | DATETIME     | 更新时间                   | ON UPDATE CURRENT_TIMESTAMP |
| is_deleted  | TINYINT(1)   | 逻辑删除（0-未删，1-已删） | 默认0                       |

### **用户角色表 (user_role)**

| 字段名  | 类型   | 说明   | 约束       |
| :------ | :----- | :----- | :--------- |
| user_id | BIGINT | 用户ID | 外键->user |
| role_id | BIGINT | 角色ID | 外键->role |

### **角色表 (role)**

| 字段名      | 类型         | 说明                | 约束 |
| :---------- | :----------- | :------------------ | :--- |
| id          | BIGINT       | 角色ID              | 主键 |
| role_name   | VARCHAR(32)  | 角色名称（如admin） | 唯一 |
| description | VARCHAR(128) | 角色描述            |      |

------

## **2. 商品模块**

### **商品分类表 (category)**

| 字段名     | 类型        | 说明                    | 约束  |
| :--------- | :---------- | :---------------------- | :---- |
| id         | BIGINT      | 分类ID                  | 主键  |
| parent_id  | BIGINT      | 父分类ID（0为一级分类） |       |
| name       | VARCHAR(64) | 分类名称                | 非空  |
| level      | TINYINT(1)  | 分类层级（1/2/3）       | 非空  |
| sort       | INT         | 排序值                  | 默认0 |
| is_deleted | TINYINT(1)  | 逻辑删除                | 默认0 |

### **商品表 (goods)**

| 字段名      | 类型          | 说明                   | 约束                        |
| :---------- | :------------ | :--------------------- | :-------------------------- |
| id          | BIGINT        | 商品ID（雪花算法）     | 主键                        |
| category_id | BIGINT        | 末级分类ID             | 外键->category              |
| name        | VARCHAR(128)  | 商品名称               | 非空，普通索引              |
| price       | DECIMAL(10,2) | 价格（单位：元）       | 非空                        |
| stock       | INT           | 库存数量               | 默认0                       |
| pic         | VARCHAR(255)  | 主图URL                |                             |
| detail      | TEXT          | 商品详情（HTML富文本） |                             |
| status      | TINYINT(1)    | 状态（0-下架，1-上架） | 默认1                       |
| create_time | DATETIME      | 创建时间               | 默认CURRENT_TIMESTAMP       |
| update_time | DATETIME      | 更新时间               | ON UPDATE CURRENT_TIMESTAMP |
| is_deleted  | TINYINT(1)    | 逻辑删除               | 默认0                       |

### **商品图片表 (goods_image)**

| 字段名    | 类型         | 说明                 | 约束        |
| :-------- | :----------- | :------------------- | :---------- |
| id        | BIGINT       | 图片ID               | 主键        |
| goods_id  | BIGINT       | 商品ID               | 外键->goods |
| image_url | VARCHAR(255) | 图片URL              | 非空        |
| sort      | INT          | 排序值（越小越靠前） | 默认0       |

------

## **3. 订单模块**

### **订单表 (order)**

| 字段名        | 类型          | 说明                       | 约束                        |
| :------------ | :------------ | :------------------------- | :-------------------------- |
| id            | BIGINT        | 订单号（雪花算法）         | 主键                        |
| user_id       | BIGINT        | 用户ID                     | 外键->user                  |
| total_amount  | DECIMAL(10,2) | 订单总金额                 | 非空                        |
| status        | TINYINT(1)    | 状态（0-待付款，1-已支付） | 默认0                       |
| payment_time  | DATETIME      | 支付时间                   |                             |
| delivery_time | DATETIME      | 发货时间                   |                             |
| receive_time  | DATETIME      | 签收时间                   |                             |
| address_id    | BIGINT        | 收货地址ID                 | 外键->user_address          |
| remark        | VARCHAR(255)  | 用户备注                   |                             |
| create_time   | DATETIME      | 创建时间                   | 默认CURRENT_TIMESTAMP       |
| update_time   | DATETIME      | 更新时间                   | ON UPDATE CURRENT_TIMESTAMP |
| is_deleted    | TINYINT(1)    | 逻辑删除                   | 默认0                       |

### **订单项表 (order_item)**

| 字段名      | 类型          | 说明                   | 约束        |
| :---------- | :------------ | :--------------------- | :---------- |
| id          | BIGINT        | 订单项ID               | 主键        |
| order_id    | BIGINT        | 订单ID                 | 外键->order |
| goods_id    | BIGINT        | 商品ID                 | 外键->goods |
| goods_name  | VARCHAR(128)  | 商品名称（冗余存储）   | 非空        |
| goods_price | DECIMAL(10,2) | 下单时价格（冗余存储） | 非空        |
| quantity    | INT           | 购买数量               | 非空        |
| total_price | DECIMAL(10,2) | 商品总价（价格×数量）  | 非空        |

| id          | BIGINT     | 购物车项ID      | 主键                        |

| update_time | DATETIME   | 更新时间        | ON UPDATE CURRENT_TIMESTAMP |

## **5. 支付与物流**

### **支付记录表 (payment)**

| 字段名       | 类型          | 说明                     | 约束                        |
| :----------- | :------------ | :----------------------- | :-------------------------- |
| id           | BIGINT        | 支付记录ID               | 主键                        |
| order_id     | BIGINT        | 订单ID                   | 外键->order                 |
| payment_type | VARCHAR(16)   | 支付方式（微信/支付宝）  | 非空                        |
| trade_no     | VARCHAR(64)   | 第三方交易号             | 唯一索引                    |
| amount       | DECIMAL(10,2) | 实际支付金额             | 非空                        |
| status       | TINYINT(1)    | 状态（0-未支付，1-成功） | 默认0                       |
| create_time  | DATETIME      | 创建时间                 | 默认CURRENT_TIMESTAMP       |
| update_time  | DATETIME      | 更新时间                 | ON UPDATE CURRENT_TIMESTAMP |

### **物流表 (delivery)**

| 字段名        | 类型        | 说明         | 约束        |
| :------------ | :---------- | :----------- | :---------- |
| id            | BIGINT      | 物流ID       | 主键        |
| order_id      | BIGINT      | 订单ID       | 外键->order |
| company       | VARCHAR(32) | 物流公司名称 | 非空        |
| tracking_no   | VARCHAR(64) | 物流单号     | 非空        |
| delivery_time | DATETIME    | 发货时间     |             |
| receive_time  | DATETIME    | 签收时间     |             |
